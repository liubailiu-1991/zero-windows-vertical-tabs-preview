# ZERO Windows 垂直标签评审

[在线交互原型](https://liubailiu-1991.github.io/zero-windows-vertical-tabs-preview/) · [首发截图对照](https://liubailiu-1991.github.io/zero-windows-vertical-tabs-preview/screenshots.html)

- [方案 A · 公开评审修订 2](demo/A/v0.10-review.2/) 保留 v0.10 的标签、分组、菜单与 ZERO 标签管理，补齐设置齿轮的显示。可打开[上次分享版](demo/A/v0.10/)。
- [方案 B · 公开评审修订 2](demo/B/v0.9-review.2/) 补回窗口菜单、站点和搜索中的标签悬停及右键、书签操作与计数、最近关闭分组和恢复入口、侧栏底部设置及尺寸校准。可打开[上次分享版](demo/B/v0.9/)。
- 两套方案使用固定样例数据与本地页面。B 支持 `?plan=b&data=many` 查看多窗口、大量标签、嵌套书签与多日记录。客户端、账号与跨设备操作仍是原型边界。

GitHub Pages 从 `main` 的根目录发布。新交互版另存到 `demo/A` 或 `demo/B` 的独立版本目录，再更新首页入口；截图和旧版保留供对照。
