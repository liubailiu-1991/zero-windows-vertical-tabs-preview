# ZERO Windows 垂直标签评审

[在线交互原型](https://liubailiu-1991.github.io/zero-windows-vertical-tabs-preview/) · [截图对照](https://liubailiu-1991.github.io/zero-windows-vertical-tabs-preview/screenshots.html)

- 方案 A 来自 v0.10，可体验标签列表、分组、右键和 ZERO 标签管理。
- 方案 B 基于 v0.9，可体验窗口切换、标签列表、站点、书签、最近关闭和全局搜索。公开版使用独立样例侧栏，展示主要操作。
- 两套方案使用固定样例数据与本地页面。B 支持 `?plan=b&data=many` 查看较多标签和书签的状态。

GitHub Pages 从 `main` 的根目录发布。更新时把新交互版放在 `demo/A` 或 `demo/B` 下的新版本目录并更新 `demo.js`。截图另存到新的 `revisions/日期` 目录，更新 `review-data.js`。
